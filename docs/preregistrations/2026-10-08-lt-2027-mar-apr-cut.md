# Pre-registration — the March–April cut of the 2027 1st-6 strip

**Registered:** 8 Oct 2026, before the 2027 1st-6 Sequence 1 auction (bids
Oct 20–22, results by Nov 5) and before any Jan–Jun 2027 delivery. The git
commit carrying this file is the timestamp.

## Where the cut comes from

The strip sheet is `strategy/lt_strip_scan.py` (methodology v1.3: each month
is valued at the worse of its two prior same-calendar months; the fade gate;
limit = value ÷ 1.5 must beat the most recent prior-sequence clear).

Backtest: the same rule, run as of October 2025 on the 2026 1st-6 Sequence 1
and graded on Jan–Jun 2026 settlement. The rule is somewhat more lenient
there, because only one prior year of prices exists (DAM data starts July
2024).

| Fills | n | Won | Return on cost |

| all | 990 | 38% | 147% |
| **March + April** | **484** | **49%** | **190%** |
| every other month | 506 | 27% | 101% |
| March + April, hub/zone leg | 106 | 74% | 211% |
| March + April, OBL | 67 | 84% | 240% |

The March–April hypothesis comes from earlier work: the two-year payout
profile (Sep 2026) found April the best-paying month in both years, matching
the maintenance-outage calendar. It wasn't tuned on this backtest. The
hub-leg and OBL sub-cuts **were** found in this backtest, so they're
in-sample and registered here only as secondary.

cost (`sum(realized) / sum(cost)`) than the January, February, May and June
rows combined.

**P3 (secondary, in-sample).** Within March–April, the filled hub/zone-leg
rows return more on cost than the filled nodal rows.
